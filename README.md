# Kayan Ai

**مشروع مساعد ذكاء اصطناعي لخدمة عملاء وجمع استفسارات عملاء كيان سوفت عبر WhatsApp.**

## الحالة الحالية
- مشروع Kapso باسم `Kayan Ai` متصل، ورقم Sandbox موجود.
- Workflow مساعد «Kayan Soft — مساعد واتساب صنعاني» نشط على Sandbox فقط.
- النموذج الحالي للمساعد في Kapso: **GPT-4.1 mini**؛ أُعيد إليه بعد تجربة Gemini بناءً على توجيه المالك.
- المساعد يرد بلهجة صنعانية ودودة، ويجمع تفاصيل طلب العميل دون اختلاق أسعار أو أوقات أو وعود غير معتمدة.
- لا يوجد ربط برقم إنتاجي، ولا مشروع Vercel أو خادم مخصص في هذه المرحلة.

## نطاق النسخة التجريبية
- التعريف بكيان سوفت ومجالاتها الرقمية المعروفة.
- فهم طلب العميل وجمع ملخص عن الخدمة والهدف والمتطلبات.
- الإحالة لموظف عند طلب العميل أو عند الحاجة لمعلومة/قرار غير متاح.
- اختبار المحادثات على Sandbox قبل أي إطلاق حقيقي.

## التقنية الحالية والمستقبلية
- **Kapso Workflows** لاستقبال رسائل WhatsApp وتشغيل المساعد.
- **GPT-4.1 mini** للنموذج الحالي بعد استعادة إعداد الوكيل السابق.
- **Vercel غير مطلوب حاليًا** لأن الـWorkflow مستضاف ويعمل داخل Kapso. يُعاد تقييم Vercel فقط إذا ظهرت حاجة لخادم مخصص أو Webhook/API أو تكامل خارجي لا يغطيه Kapso.
- لا تُرفع مفاتيح API أو الرموز أو بيانات العملاء إلى GitHub. تحفظ الأسرار في مخزن الأسرار للخدمة التي تستخدمها، أو في متغيرات بيئة محمية عند إضافة خادم.
