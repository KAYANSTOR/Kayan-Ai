# Kayan Ai

**مشروع لبناء وكيل ذكاء اصطناعي لخدمة العملاء والحجوزات عبر WhatsApp.**

## الفكرة
يستقبل الوكيل رسائل العملاء، يفهم احتياجاتهم، يجيب عن الأسئلة وفق معلومات النشاط التجاري، ويُساعد في حجز المواعيد أو تحويل المحادثة إلى موظف عند الحاجة.

## نطاق النسخة الأولى
- تجربة آمنة عبر رقم WhatsApp Sandbox قبل ربط رقم حقيقي.
- الرد على الأسئلة الشائعة باستخدام معلومات موثوقة يزودنا بها صاحب النشاط.
- جمع بيانات طلب الحجز والتحقق من توفر المعلومات اللازمة.
- تأكيد الحجز أو إحالته للموظف وفق آلية واضحة.
- دعم التحويل إلى موظف عند عدم اليقين أو طلب العميل.
- مراعاة الخصوصية، وعدم وضع الأسرار أو بيانات العملاء في المستودع.

## خارطة الطريق
راجع [خطة المشروع](docs/PROJECT_PLAN.md) للتفاصيل والمراحل ومعايير القبول.

## التقنية المقترحة مبدئيًا
- WhatsApp Cloud API عبر Kapso، بعد التحقق من ملاءمة التكلفة والاحتياجات.
- بيئة اختبار Sandbox قبل أي إطلاق حقيقي.
- تحديد طبقة الذكاء الاصطناعي والتخزين والتكاملات بعد حسم المتطلبات.

> هذه الخيارات أولية وليست قرارات نهائية. لا تُضف مفاتيح API أو رموز الدخول أو بيانات شخصية إلى Git.

## الحالة
**مرحلة التخطيط والتحقق من المتطلبات.** لا يوجد تكامل إنتاجي أو رقم WhatsApp حقيقي مرتبط حتى الآن.
